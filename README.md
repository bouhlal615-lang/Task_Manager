
# Task Manager

## Description
Task Manager est une application web développée
avec React et Redux Toolkit.

Elle permet de gérer une liste de tâches.

## Technologies utilisées
- React
- Vite
- Redux Toolkit
- React Redux
- JavaScript

## Fonctionnalités
- Ajouter une tâche.
- Supprimer une tâche.
- Modifier le statut d'une tâche.
- Afficher la liste des tâches.

## Installation

Cloner le projet :

```bash
git clone URL_DU_PROJET
```

Entrer dans le dossier :

```bash
cd task-manager
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet :

```bash
npm run dev
```
